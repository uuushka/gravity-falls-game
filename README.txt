Сайт Gravity Falls: Тайна пятой страницы

Публикация на GitHub Pages:
1. Создайте публичный репозиторий gravity-falls-game.
2. Загрузите файл index.html в корень репозитория (Add file → Upload files).
3. В Settings → Pages задайте Source: Deploy from a branch, Branch: main, Folder: /(root), Save.
4. Откройте https://<username>.github.io/gravity-falls-game/ .

В игре использован веб-шрифт Google Fonts; без интернета сработает резервный системный шрифт.
