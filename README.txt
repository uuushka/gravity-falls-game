Gravity Falls — Тайна пятой страницы, версия 2 (мобильная).

Для GitHub Pages достаточно заменить СТАРЫЙ index.html в корне репозитория на НОВЫЙ index.html из этого архива.
Остальные файлы репозитория можно оставить без изменений.

Новая версия:
— автоматически подстраивает игровое поле под вертикальный и горизонтальный экран iPhone;
— сенсорные кнопки расположены прямо на игровом поле, не создают лишней прокрутки;
— модернизированное стартовое окно и HUD;
— узнаваемые арты персонажей вместо условных фигур.

Игра работает без интернета со встроенными в HTML нарисованными персонажами. При доступности внешнего сервера она пробует подгрузить полноразмерные изображения персонажей Gravity Falls с StickPNG. Если изображения не загружаются, используется локальная версия.
Изображения: https://www.stickpng.com/img/cartoons/gravity-falls/dipper-pines ; https://www.stickpng.com/img/cartoons/gravity-falls/mabel-pines ; https://www.stickpng.com/img/cartoons/gravity-falls/gravity-falls-bill-cipher .
Правообладателям Gravity Falls принадлежат соответствующие права на персонажей и мир. Проект предназначен только для личного некоммерческого использования; коммерческая публикация может потребовать разрешения.

Чтобы браузер подхватил изменения, после обновления GitHub Pages перезагрузите страницу с очисткой кэша.
