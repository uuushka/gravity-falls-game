# Gravity Falls: Тайна пропавшей страницы · мобильная v4

Пять глав фан-игры для телефона. Откройте `index.html` в Safari или опубликуйте его на GitHub Pages.

## Управление
- Левый виртуальный джойстик — движение; тап по дороге — пройти к точке.
- Кнопка «Прыжок» — прыжок над ловушками и врагами.
- Кнопка «Свет / Звезда / Взять» — действие или взаимодействие с уликой.
- Верхний портрет — переключить Диппера / Мэйбл.
- Пауза — звук, рестарт, выход.
- Никакой клавиатуры не требуется.

## Особенности главы 1
1. Найти и осветить скрытый в шкафчике обрывок Диппером.
2. Запомнить три символа; верно воспроизвести по памяти.
3. У двойной двери сначала Диппер сканирует знак, затем Мэйбл разбивает печать звездой.
4. Второй обрывок охраняет гном: Мэйбл оглушает его звездой.
5. Преодолеть ловушки, открыть третий обрывок и выйти. 3 сердца — ловушки не декоративные.

## Обновление GitHub Pages
Откройте https://github.com/uuushka/gravity-falls-game, замените **корневой `index.html`** этим файлом и сохраните commit. Не заливайте ZIP как единый файл — его надо распаковать. Никаких сторонних ресурсов не требуется.

Версия не размещена автоматически в репозитории: для пуша нужен авторизованный GitHub-доступ. Номер V4 виден в игре и позволяет отличить новую версию от старой, если сайт показывает кеш.

Неофициальная фан-игра, не продукт правообладателей. Изображения — собственные векторные стилизации, а не официальные кадры мультсериала.
