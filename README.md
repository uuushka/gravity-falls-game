# Gravity Falls: Пять искажений — мобильная V5

Некоммерческая фанатская игра для мобильного браузера. Весь проект находится в одном файле `index.html`. Не нужны внешние библиотеки или загрузка изображений из сети: персонажи встроены в HTML.

## Пять разных игр

1. **Хижина чудес** — point-and-click расследование: ищи 5 улик и решай кодовый замок. Управление: касания.
2. **Побег от гномов** — аркадная погоня на трёх дорожках: уклоняйся и прыгай. Управление: свайпы влево/вправо/вверх или большие экранные кнопки.
3. **Озеро двойников** — 3 зеркальных лабиринта: один герой повторяет движение другого по горизонтали наоборот. Управление: свайпы или экранные стрелки.
4. **Бункер Форда** — 3 задачи с лазерными зеркалами. Управление: касайся зеркал, затем «Запустить луч».
5. **Последний трюк Билла** — битва на память и реакцию: воспроизводи знаки, подбирай щит. Управление: четыре крупные сенсорные плитки.

Приблизительная длительность: главы 1, 3, 4 и 5 зависят от скорости решения; глава 2 длится 88 секунд при успешном прохождении.

## Публикация на GitHub Pages

Заменить файл `index.html` в **корне** репозитория `uuushka/gravity-falls-game`. Оставить настройки GitHub Pages: ветка `main`, каталог `/(root)`. После коммита обновить страницу (если старый интерфейс кэшируется, обновить принудительно).

## Тестирование

Проверено в Chromium в мобильных размерах 390×844, 375×667, 320×568. Автоматически проверено: правильный код расследования, три зеркальных лабиринта, решения трёх лазерных контуров, победа над Биллом. Не проверено непосредственно в Safari на физическом iPhone.
